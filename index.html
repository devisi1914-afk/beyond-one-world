    Statistics

    A qualitative concept analysis of the six sources. Every text was read against the same framework, so the profiles can be compared: concepts are grouped, counted, and categorised by frequency using fixed thresholds.

    Method. All frequencies are counted directly from the source PDFs. Running page headers and the reference list are removed before counting, and each concept group is matched by an explicit set of word forms, so no occurrence is counted under two groups. Alongside frequency, each concept records the number of pages it appears on — a concept can be frequent yet confined to one stretch of a text.
